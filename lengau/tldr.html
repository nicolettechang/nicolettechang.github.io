TL;DR

Just the commands

Know your way around a cluster? These are the commands, one line each. Type your Lengau username and your drive below, then swap in your own DIRNAME. The other tabs explain each step.

Filled in for you if you set them on the Checklist. Kept in this browser only.

run on your computer  ·  run on Lengau

On Lengau

  • Log in
    ssh USERNAME@lengau.chpc.ac.za
  • Size what is in a folder, largest last
    du -sh * .[!.]* 2>/dev/null | sort -h
  • Killed? Get a compute node for up to 4 hours
    qsub -I -q serial -P ERTH0834 -l select=1:ncpus=1 -l walltime=04:00:00
  • Record your modules
    module list > modules.txt 2>&1
  • Record a conda environment
    conda env export -n ENVNAME > ENVNAME.yml
  • Record your crontab
    crontab -l > crontab.txt
  • Record a conda environment, only what you asked for (rebuilds on a new system)
    conda env export -n ENVNAME --from-history > ENVNAME_asked_for.yml
  • Record your pip packages, or those in a virtual environment
    python3 -m pip list --user --format=freeze > pip_user.txt; VENV/bin/python -m pip freeze > VENV.txt
  • Keep your config files (not your private ssh keys, .netrc or API keys)
    cp -p ~/.bashrc ~/.bash_history ~/.gitconfig ~/.vimrc ~/.tmux.conf ~/.ssh/config . 2>/dev/null; cp -rp ~/.vim ~/bin . 2>/dev/null
  • Work in a git repository that is only on Lengau: changed files, then commits not pushed
    git -C REPO status -s; git -C REPO log --branches --not --remotes --oneline
  • Compress a NetCDF file, losing nothing
    nccopy -d 1 -s in.nc out.nc
  • Make a tarball from a directory
    tar cf DIRNAME.tar DIRNAME
  • Make a compressed tarball (worth it for text, not NetCDF)
    tar czf DIRNAME.tar.gz DIRNAME
  • Check a tarball
    tar tf DIRNAME.tar > /dev/null && echo OK

On your computer

  • Copy a directory. Run it again if the VPN drops: it carries on
    rsync -rt --partial --progress USERNAME@lengau.chpc.ac.za:/mnt/lustre/users/USERNAME/DIRNAME /path/to/drive/
  • Stream a directory of many small files: nothing written on Lengau
    ssh USERNAME@lengau.chpc.ac.za "cd /mnt/lustre/users/USERNAME && tar cf - DIRNAME" | tar xf - -C /path/to/drive/
  • Copy a tarball
    rsync -t --partial --progress USERNAME@lengau.chpc.ac.za:/mnt/lustre/users/USERNAME/DIRNAME.tar /path/to/drive/
  • Check a copied directory: prints nothing but skipped links when it is all there
    rsync -rtn --itemize-changes USERNAME@lengau.chpc.ac.za:/mnt/lustre/users/USERNAME/DIRNAME /path/to/drive/
  • Unpack a tarball
    tar xf DIRNAME.tar -C /path/to/drive/
  • Keep a Mac awake while a command runs: put this in front of it
    caffeinate -i
  • List what is on the drive
    ls -lR /path/to/drive > /path/to/drive/CONTENTS.txt

Several directories: a loop

Any of the lines above works in a for loop, in a script or at the prompt. Make a tarball of each, on Lengau:

for d in DIR1 DIR2 DIR3; do tar cf $d.tar $d && tar tf $d.tar > /dev/null && echo "OK $d" || echo "FAILED $d"; done

Copy each to the drive, on your computer. Run it again for any that say FAILED:

for d in DIR1 DIR2 DIR3; do rsync -rt --partial USERNAME@lengau.chpc.ac.za:/mnt/lustre/users/USERNAME/$d /path/to/drive/ && echo "OK $d" || echo "FAILED $d"; done
