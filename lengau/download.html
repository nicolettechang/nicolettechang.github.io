Explainer Three ways a folder is downloaded

Each item on your list comes down one of three ways:

  • Tarballs (.tar or .tar.gz), packed on Lengau in Part 4: each arrives as one file, links included, on any drive.
  • Folders as they are, for big folders of data files. rsync leaves links out and says skipping non-regular file for each one.
  • Streamed, for folders of many small files: packed on Lengau as it is sent and unpacked on your drive as it arrives, links included.

If the VPN drops, run the rsync command again and it carries on where it stopped. A stream can't carry on, so each streamed folder has an rsync command under it that copies only what is missing.

    Write down what is on the drive

    • Label the drive with your name and the date.
    • Tell the data manager which drive it is and what is on it.
    • Irreplaceable? Make a second copy, on a second drive or on DIRISA. A single drive is one drop away from losing it all.

    Windows

    1. In PowerShell, opened as administrator: wsl --install, then restart.
    2. Open Ubuntu and run sudo apt update && sudo apt install -y rsync.
    3. Choose Windows under Your details, with your drive's letter.
    4. If Ubuntu cannot reach Lengau while the VPN is on, try ssh from PowerShell. If that works, ask the data manager for help with the copy.
